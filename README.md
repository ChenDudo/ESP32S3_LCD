## 目录约定

每个项目统一按下面的结构组织，新增项目照此建：

```
projects/<项目名>/
├── README.md       项目总览：需求、当前状态、待办
├── 硬件设计/        原理图、BOM、引脚表、评审意见
├── 外壳设计/        结构说明、CAD 源码、交付物（STL/STEP）
├── firmware/       固件工程（目录名必须 ASCII）
└── 硬件资料/        原厂资料、数据手册、供应商资料
```

两条硬规则：

1. **固件目录必须是纯 ASCII 路径**（`firmware/`，不是 `固件设计/`）。PlatformIO / ESP-IDF 对中文路径的报错经常指向莫名其妙的地方。
2. **文档给结论，不给过程**。尺寸、型号、公差直接写数字。

## 版本命名

设计文档用 `rev X.Y` 递增：改尺寸/位置/器件算次版本，改方案架构算主版本。文档头部注明变更点。

## 换机器继续开发

```bash
git clone git@github.com:ChenDudo/ESP32S3_LCD.git
```

固件依赖靠 `platformio.ini` 锁定版本，首次编译时自动下载；`硬件资料/` 里的原厂 PDF 已入库，不需要额外找。
