# ESP32S3-LCD 全覆盖外壳设计（Rev I）

为 **ESP32-S3 + ATK-MD0350 3.5 寸 TFT LCD 底板** 设计的不透明、全覆盖 3D 打印外壳。
当前定稿 **Rev I（2026-11-08）**：修复 Rev A~H 一直存在的装配硬伤——**4 颗 M3 不再穿过 PCB**，改走 PCB 板框之外的四角连接柱；PCB 改由**2 个对角定位销（1 圆销 + 1 菱形销）**定位（11-08 按 A 方案修正 4 销过约束）。顶板外表面一体成型 5 组接口凸字 `USB / COM / Power / 5P / RST`。上盖顶板仍完整不镂空、只保留单一显示窗 `74.40 × 50.00`（按实测 A.A 放大让位）；四边接口统一开口带，天线端从侧壁让位窗伸出壳外；无磁吸。

> 打印发给商家用 `.stl`；在 CAD 里看图/改尺寸用 `.step` / `.FCStd`；尺寸依据是 PDF / DXF。
> 逐文件索引见同目录 [`文件清单.csv`](文件清单.csv)。

**2026-11-08 补修（Rev I 文档同步，几何不变）**：工程图第 3 页「装配顺序」第 4 步此前仍是 Rev H 的「穿 PCB φ4 孔拧进上盖柱」，与 Rev I 结构矛盾，已改为「直接拧进四角连接柱（不穿 PCB / LCD）」；报价表删除 Rev H 遗留的 `φ4→φ3 尼龙衬套`；工程图天线净空说明、三视图图例、下单说明中的「螺丝柱」称谓统一为「四角连接柱」。STL / STEP / FCStd / 预览图的几何与尺寸未改动。

**2026-11-08 追加修订（Rev I 几何有改动，打样需重新上传两个 STL）**：

1. **用户选定 A 方案，4 销改 2 销**。原 4 个 `Φ3.8` 定位销是过约束：销 / `φ4` 孔单边间隙仅 `0.10 mm`，而 SLA `±0.2 mm` 或 `0.3%` 收缩在对角距 `103.51 mm` 上可达 `0.31 mm`，常出现「前三颗进去、第四颗顶住、PCB 落不到底」。现改为 `HOLES[0]` 圆销（主定位）+ `HOLES[3]` 菱形销（次定位，沿两销连线削扁到 `3.20`）：连线方向留 `0.40 mm` 单边间隙吸收收缩，垂直方向仍由 `Φ3.8` 接触定位，平面 3 自由度刚好约束完。另 2 个 `φ4` 孔空置、只由 `Φ7` 支撑台托底。
2. **顶板新增 5 组一体成型接口凸字**：`USB` / `COM`（下边双 Type-C 左 / 右）、`Power`（右边 5V Type-C）、`5P`（右边 XH2.54-5P）、`RST`（上边复位孔右侧）。字高 `3.20`、凸出 `0.40`、底面嵌入顶板 `0.05`；字形由 `cad/text_geom.py` 用 matplotlib 自带 DejaVuSans-Bold 生成（含字母内孔），STL / STEP / DXF / PDF / 预览五处完全一致；DXF 新增 `MARK` 层。5 组字都在显示窗外的顶板边框带内，距窗口 ≥2.87、距外形边 ≥2.19 mm，不碰复位孔 / 连接柱，绝缘树脂不影响天线。
3. **几何与校验**：上盖 `12.72 cm³`（+0.03，凸字）、底座 `19.47 cm³`（−0.03，少 2 销），合计 `32.18 cm³`；上盖顶面 `Z=16.40`。两个 STL 均水密单实体（`body_count=1`），16 个字母凸台在 `Z=16.20` 全部命中、`Z=16.50` 全部不命中；STEP 3 件、FCStd 3 对象、4 个 DXF `INSUNITS=4`、8 个脚本语法全部通过，工程图 / 三视图 / 预览已渲染目视复核。
4. **给商家**：凸字与壳体一体打印不额外收费；后处理仍选「**不需要打磨**」，不要把字磨平或喷漆盖住（想更清晰可用黑色模型漆 / 马克笔涂凸字表面）。

### Rev I 的判断依据（无需实物拍照即可定案）

ATK-MD0350 用户手册 **图 3.1**（渲染图见 `ref/输入资料/资料图_ATK-MD0350_模块尺寸_*.png`）：模块 PCB 底板 `56.41 × 97.92`，两个安装孔只在 ALIENTEK 一端、孔距 `48.64`，短边余量每侧 `3.885`。
PCB 同侧两孔距 `48.695`，与 `48.64` 只差 `0.055 mm` → LCD 两孔对准 PCB 一端两孔。
按孔心到板端 `2.53` 或 `3.94` 两种读法，LCD 板在 PCB 长边坐标分别为 `0.27~98.19` / `1.68~99.60`，**完全落在 PCB 板框投影内**，四角 `φ4` 孔（4.317 / 95.66）全部被覆盖；左端是实心板、无让位孔。
因此从底部上来的 M3 螺杆在 `Z≈5.0~12.1` 段被 LCD 板挡死：缩小柱径、换 M2、去掉 LCD 螺丝都无效，只能把连接点移出 LCD 板投影。

新柱位核算：柱心到 PCB 板框 `R2` 圆角实体净距 `3.80` ≥ 柱半径 `3.00`（余量 `0.80`）；柱圆完全落在 `R4.5` 外圆角轮廓内（`4.41 ≤ 4.50`）；按两种板端读法，柱圆到 LCD 板最小净距 `1.59 / 1.66 mm`，**均无干涉**。

> Rev H 的判断修正：Rev G 的两版窗口都比 A.A 小，"压边"实际压的不是黑边，而是把亮区边缘像素切掉了。既然宁可装配偏差也不遮挡显示内容，窗口应比 A.A 略大而非略小。
> 偏心量依据：LCM 规格书 `OUTLINE 84.69×55.26` / `A.A 73.44×48.96` 长边尺寸链偏心 2.77 mm，短边左右各 3.15 对称；用户实物图逐像素换算 2.52 mm，取 2.75。**打样前务必实测**：量「亮区左缘→模块左缘」= L、「亮区右缘→模块右缘」= R，`(L−R)/2` 即应填的 `WIN_OFFSET_X`（偏左为负）。

## 5. 修改后如何重出全套文件

**依赖**：Python 3.13；`trimesh`、`shapely`、`manifold3d`、`ezdxf`、`reportlab`、`pymupdf`、`matplotlib`、`pillow`、`numpy`、`scipy`；STEP 需要 `cadquery`（含 OCP / OpenCascade）；`.FCStd` 需要本机 FreeCAD 1.1.4 的命令行内核 `C:\Program Files\FreeCAD 1.1\bin\freecadcmd.exe`。

工作目录必须是 `cad/`（脚本内全部为相对路径，仓库里保持原目录结构就是为此）：

```bash
cd 外壳设计/cad
python build_v2.py          # STL / DXF / 报价 / 下单说明 / geom_v2.json
python make_pdf_v2.py       # 3 页 A4 工程图
python make_views.py        # A3 三视图 PDF + DXF
python build_step.py        # 3 个 STEP 解析实体（上盖 / 底座 / 装配体）
python make_preview.py      # 俯视 / 等距预览 PNG
"C:/Program Files/FreeCAD 1.1/bin/freecadcmd.exe" build_fcstd.py   # .FCStd 工程
```

改任一参数（尤其 `WIN_OFFSET_X`、`WIN_W` / `WIN_H`、`GAP` / `EDGE`、`SCREW_C`、`Z_TOP_IN`、开窗宽度、`TEXT_MARKS` / `TEXT_SIZE` / `TEXT_RAISE`、`LOCATOR_POS` / `DIAMOND_W`）后 **必须六个脚本全部重跑**，否则 STL / STEP / FCStd / PDF / 预览会互相不一致。`build_step.py` 与 `build_v2.py` 共用 `params_v2.py`；`text_geom.py` 是被 `build_v2.py` / `build_step.py` / `make_preview.py` 导入的共用字形与菱形销截面模块，**无需单独运行**，几何写入 `geom_v2.json` 后供 PDF / 三视图读取；FreeCAD 宏 `deliverables/FreeCAD_一键生成工程.FCMacro` 只补颜色与视角，不改变几何。
历次一次性批量修订脚本（`patch_v3~v8.py`）未归档到本目录，需要时见 git 提交 `9732bd3` / `a0eb3a6`；**不要重复执行**。

## 8. 已知限制与注意

- **外形变大的取舍**：为把 4 颗螺丝移出 LCD 板投影，长宽各 +6.00 mm（面积约 +15%），偏离最初「尽量贴近 PCB」的要求。若必须保持 `105.20×67.00`，替代方案是「右侧 2 颗加长 M3 穿过 LCD 安装孔 + 左侧 2 个弹性卡扣」，但只剩 2 颗螺丝、卡扣对 3D 打印精度与材料韧性敏感，需整套重出。
- **PCB 垂直方向留约 2.1 mm 间隙**：顶板内表面 Z=14.20、LCD 板顶约 12.10，靠 2 个对角定位销水平定位 + 4 个支撑台托底；另 2 个 `φ4` 孔空置。若装配后觉得晃，在顶板内侧贴 1~2 mm 自粘泡棉垫即可；不要加高柱或缩小显示窗。
- **PCB 底面净空只有 1.00 mm**：核心板排针直焊的背面焊点若突出 >1 mm 会顶到底板，装配前务必实测；A 方案已消除定位销顶住 PCB 的风险，但底面焊点是另一个独立风险点。
- **没有 DWG**：官方 CAD 云端服务当时不可用（`CAD_LLMROUTER_UNAVAILABLE`），交付的是 **DXF R2010 / mm（`INSUNITS=4`）**，可在 AutoCAD / 立创 EDA 里另存为 DWG；DXF 是二维工程图，不含 3D 实体。
- **扩大窗口的取舍**：理想装配下四周会露出 ≤0.5 mm 极窄黑边（左侧原黑边约 2.86、右侧约 8.39，绝大部分仍被顶板压住）；换来的是任何装配偏差下都不会遮挡显示内容。若追求「一丝黑边都不露」，把 `WIN_W/WIN_H` 改回等于或略小于 A.A 即可，但会恢复切亮区风险。
- **打印以 STL 为准**；STEP（AP214 BREP）与 `.FCStd` 用于 CAD 看图、测量、改特征。装配体 STEP / FCStd 里的 `PCB_Reference` 只是间隙检查参考件，**不是打印件**。
- `.FCStd` 由命令行内核生成，不含 GuiDocument（颜色 / 相机）；想要着色版执行 FreeCAD 宏即可。
- 顶板天线区不开洞、不加支撑；天线端朝外或悬出安装面边缘，避免整块金属背板贴近。
- 若此 GitHub 仓库为公开仓库：`ref/esp32s3_lcd/ESP32S3_LCD.epru` 是完整 EDA 工程源数据，`ref/输入资料/` 含 PCB 导出图，请确认是否愿意公开后再推送。
