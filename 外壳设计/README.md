# ESP32S3-LCD 全覆盖外壳设计（Rev I）

为 **ESP32-S3 + ATK-MD0350 3.5 寸 TFT LCD 底板** 设计的不透明、全覆盖 3D 打印外壳。
当前定稿 **Rev I（2026-11-08，第六次追加修订）**：修复 Rev A~H 一直存在的装配硬伤——**4 颗 M3 不再穿过 PCB**，改走 PCB 板框之外的四角连接柱；PCB 改由**2 个对角定位销（1 圆销 + 1 菱形销）**定位。顶板外表面一体成型 **9 组接口凸字** `USB / COM / POWER / UART / RST / I2C1~I2C4`，字高 `2.40`、贴近接口（右侧 `POWER` / `UART` 竖排字头朝左，上边 `I2C1~I2C4` 与 `RST` 字头朝上）。顶板完整不镂空、只保留单一显示窗 `74.40 × 50.00`（按实测 A.A 放大让位）；**窗口中心 `X=52.85 / Y=35.60`，相对外壳中心左移 `2.75`、下移 `0.90`（不是 Y 轴几何居中）**；**开口带按接口 Z 基准分两组**：A 组（PCB 直焊：上边 I2C / 天线、右边 5V / XH-5P）`Z 4.00~12.20`，B 组（下边核心板双 Type-C）`Z 6.00~16.20`（核心板直焊在 PCB 之上，插口中心 `Z 10.90`，旧上沿 12.20 会顶住线头壳）；天线端从侧壁让位窗伸出壳外；无磁吸。**外形 `111.20 × 73.00 × 25.10`（凸字顶 25.50）**：第五次修订按「2.54 贴片排针 + 贴片排母」堆叠重算 Z，旧版 `16.00` 总高装不下 LCD，已加高 `9.10`，详见第 4 节 Z 堆叠校核；第六次修订把下边双 Type-C 窗单独抬高，详见第 4 节「第六次追加修订」。

> 打印发给商家用 `.stl`；在 CAD 里看图/改尺寸用 `.step` / `.FCStd`；尺寸依据是 PDF / DXF。
> 逐文件索引见同目录 [`文件清单.csv`](文件清单.csv)。

**2026-11-08 第六次追加修订（当前定稿；双 Type-C 开口带单独抬高，打样必须重新上传上盖 STL）**：

1. **用户指出的问题**：双 Type-C 在 ESP32 核心板上，核心板直焊在 PCB **之上**；其 Z 基准要逐级累加「底板 + 支撑台 + PCB + 核心板排针 + 核心板 PCB + Type-C 座 + 插入的线头壳」，而其余接口直接焊在 PCB 顶面，两者**底部并不持平**，不能共用一条 `Z 4.00~12.20` 统一开口带。
2. **Z 堆叠核算（B 组，自外壳底面 Z=0 起算）**：

   | 层 | 厚度 | 累计 Z | 依据 |
   |---|---|---|---|
   | 底座底板 | 2.40 | 2.40 | `T_BASE` |
   | 4 个 Φ7 支撑台 | 1.00 | 3.40 | `Z_PCB_BOT` |
   | PCB | 1.60 | 5.00 | `Z_PCB_TOP` |
   | 核心板直焊排针塑高 | **2.50** | 7.50 | `.epru` BOM `LAIL-PZ2.54-*`（塑高 2.50 / 配合针长 6.00） |
   | 核心板 PCB | 1.60 | **9.10** | `ESP32-S3-Metric.pdf`：63.39×27.94、两侧 2×22 通孔焊盘 |
   | Type-C 母座口中心高出板面 | 1.80 | **10.90** | 原理图 `TYPEC-304-BCP16` 16P，座高约 3.60（通用规格，待实测） |
   | 插入的线端注塑壳 | 8.00 厚 | 壳底 6.90 / **壳顶 14.90** | 通用 USB-C 线头壳 12~16 宽 × 6~8 厚 |
   | 上 / 下插拔与公差余量 | +1.30 / −0.90 | **开口 6.00~16.20** | 手指握持 + 线材上翘 + SLA ±0.2 |

   **结论**：旧统一上沿 `12.20` 会被壳顶 `14.90` 顶住 `2.70 mm`，连插拔余量共缺 `4.00 mm`。A 组（PCB 直焊）插口中心 ≈`6.6~7.0`、壳顶 ≤`11.0`，`12.20` 仍够，故**只抬高下边这一组**，上沿到顶板内表面 `23.30` 仍留 `7.10` 实壁。
3. **安装方式澄清**：用户 11-08 明确 `.epru` BOM 里的 `ZX-PM2.54-1-22PY`「1×22P 直插排母、塑高 8.50」**不焊接**；核心板用 `LAIL-PZ2.54-*` 排针直接焊到 PCB 通孔，板间距取 `2.50`，不按 `8.50` 计算。
4. **参数改动**：`params_v2.py` 新增 `CORE_* / CABLE_* / DUAL_Z*` 常量与完整校核链；`slots()` 给 `DUAL-USBC` 窗单独赋 `DUAL_Z0 / DUAL_Z1`，其余 4 个窗仍用 `OPEN_Z0 / OPEN_Z1`。`OPEN_Z1=12.20`、`POST_PILOT_Z1=13.80` 的固定值不变。
5. **同步范围**：STL / STEP / FCStd / 4 个 DXF / A4 3 页工程图 / A3 三视图 / 俯视与等距预览 / 报价 CSV / 给商家的下单说明 / `geom_v2.json` 全部重出。上盖体积 `19.10 → 18.98 cm³`（下边窗抬高多挖掉材料），合计 `38.45 cm³`。

## 8. 已知限制与注意

- **外形变大的取舍**：为把 4 颗螺丝移出 LCD 板投影，长宽各 +6.00 mm（面积约 +15%），偏离最初「尽量贴近 PCB」的要求。若必须保持 `105.20×67.00`，替代方案是「右侧 2 颗加长 M3 穿过 LCD 安装孔 + 左侧 2 个弹性卡扣」，但只剩 2 颗螺丝、卡扣对 3D 打印精度与材料韧性敏感，需整套重出。
- **PCB 垂直方向留约 1.00 mm 间隙**：顶板内表面 `Z=23.30`、LCD 顶面约 `22.30`，靠 2 个对角定位销水平定位 + 4 个支撑台托底；另 2 个 `φ4` 孔空置。若装配后觉得晃，在顶板内侧贴 1~2 mm 自粘泡棉垫即可；不要缩小显示窗。
- **PCB 底面净空只有 1.00 mm**：核心板排针直焊的背面焊点若突出 >1 mm 会顶到底板，装配前务必实测；A 方案已消除定位销顶住 PCB 的风险，但底面焊点是另一个独立风险点。
- **开口带分两组、别混用**：A 组上沿 `12.20` 是按 PCB 直焊口与常见 Type-C 线头（注塑壳 6~8 厚）留的下限附近；B 组上沿 `16.20` 是按核心板 Z 链与同一线头壳算的。若实物线端注塑壳明显更厚、或 XH2.54-5P 带扣大插头插不到底，分别调 `OPEN_Z1`（A 组）或 `CABLE_SHELL_H / DUAL_Z1`（B 组）后重跑六个脚本；两组都**不要跟随 `Z_TOP_IN`**，也不要让 A 组超过 `21.00`，否则又会把侧壁挖穿到顶板内表面。
- **没有 DWG**：官方 CAD 云端服务当时不可用（`CAD_LLMROUTER_UNAVAILABLE`），交付的是 **DXF R2010 / mm（`INSUNITS=4`）**，可在 AutoCAD / 立创 EDA 里另存为 DWG；DXF 是二维工程图，不含 3D 实体。
- **扩大窗口的取舍**：理想装配下四周会露出 ≤0.5 mm 极窄黑边（左侧原黑边约 2.86、右侧约 8.39，绝大部分仍被顶板压住）；换来的是任何装配偏差下都不会遮挡显示内容。若追求「一丝黑边都不露」，把 `WIN_W/WIN_H` 改回等于或略小于 A.A 即可，但会恢复切亮区风险。
- **打印以 STL 为准**；STEP（AP214 BREP）与 `.FCStd` 用于 CAD 看图、测量、改特征。装配体 STEP / FCStd 里的 `PCB_Reference` 只是间隙检查参考件，**不是打印件**。
- `.FCStd` 由命令行内核生成，不含 GuiDocument（颜色 / 相机）；想要着色版执行 FreeCAD 宏即可。
- 顶板天线区不开洞、不加支撑；天线端朝外或悬出安装面边缘，避免整块金属背板贴近。
