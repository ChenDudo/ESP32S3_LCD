# 硬件资料

本目录存原厂资料、数据手册与实测记录。文件名带版本，修改前先看日期，不要覆盖原厂文件。

## 显示屏：中景园 ZJY133T-IG01（本项目已定案）

厂商资料整包在 [`中景园1.3寸240X240 TFT LCD技术资料/`](中景园1.3寸240X240%20TFT%20LCD技术资料/)。
整包里同一块 1.3″ 屏按「玻璃厂 × 连接方式」分成 6 个变体，**本项目只用下面这一个**：

```
中景园1.3寸240X240 TFT LCD技术资料/
├── 瀚彩玻璃/                                   ← 本项目选瀚彩（HSD）
│   ├── 1.30IPS焊接12pin-…-HSD-ZJY133T-IG01/   ← ✅ 本项目用这个（焊接式 12pin）
│   ├── 1.30IPS插接12pin-…-ZJY133TP-IF51/      ← 插接式，要买 FPC 座，不用
│   └── 1.30IPS插接24pin-…-ZJY133T-IF05/       ← 24pin（RGB 并口），不用
└── 深超玻璃/                                   ← 深超（CTC）玻璃，同规格备选，不用
```

选定变体目录里的关键文件：

| 文件 | 用途 |
|---|---|
| `01-规格书与芯片手册/ZJY133T-IG01.pdf` | 模块规格书（18 页）：机械图、引脚、电气、光学、可靠性 |
| `01-规格书与芯片手册/ST7789V3_SPEC_Preliminary_V0.0_200102(1).pdf` | 驱动 IC 手册，寄存器与 AC 时序以此为准 |
| `02-原理图/1.3-SPI原理图.pdf` | 厂家参考电路（背光用 S8550 + 10 Ω） |
| `03-程序源码/11-…STM32F103硬件SPI+DMA例程/HARDWARE/LCD/lcd_init.c` | **本屏实测可用的初始化序列**，IPS 的 VCOM/gamma 都在里面 |
| `03-程序源码/…`（其余 10 个例程） | C51 / STM32 各型号的 SPI 例程，参考时序与取模 |

> `03-程序源码` 里是 Keil 工程，含大量编译产物；只读 `HARDWARE/LCD/` 下的 `lcd_init.c` / `lcd.c` 即可，别把工程拷进固件目录。

### 采购注意

- 下单认准型号 **ZJY133T-IG01**（瀚彩玻璃、焊接 12pin）。同系列 `IF51` 是插接 12pin、`IF05` 是插接 24pin，封装完全不同。
- 焊接式没有连接器，FPC 金手指直接焊在 PCB 焊盘上；0.7 mm 间距可以手工焊，但建议钢网 + 热风或热压。
- 屏幕是**裸屏模组**（含背光、铁框、FPC），不含 PCB、不含触摸。**触摸要另配**，本项目不做触摸。
- 出厂 FPC 是折起来的，焊接前要展开；折弯方向见规格书第 5 页，别反向折。
