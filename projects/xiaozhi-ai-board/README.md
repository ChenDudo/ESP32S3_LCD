# 小智 AI 板

基于 ESP32-S3 的桌面语音终端，可跑通 `xiaozhi-esp32` 官方固件：离线唤醒、全双工对话、拨轮操作、1.3″ 屏表情。

当前状态：**结构方案 rev 2.0（64×64×22 + TF 卡 + 三向拨轮 + AHT20 环境温度采样 + 内置喇叭）、硬件设计说明 rev 1.9、显示屏接口设计定稿，尚未画原理图、未投板。**

## 核心规格

| 项 | 取值 |
|---|---|
| 整机尺寸 | **64 × 64 × 22 mm**（平放桌面，底面零开孔） |
| PCB | **58 × 52 × 1.6 mm**，4 层；顶部 6mm 天线禁铜 |
| 主控 | ESP32-S3-WROOM-1-**N16R8**（16MB Flash / 8MB PSRAM，R8 是硬门槛） |
| 显示 | **中景园 ZJY133T-IG01**：1.3″ IPS 240×240，ST7789V2，4 线 SPI，12pin 焊接 FPC（0.7mm 间距），自带背光 40mA；屏中心 (30.0, 33.0) |
| 存储 | **microSD（TF）**：SPI3 独立总线 20MHz，自弹式卡座在右壁上方，≤32GB FAT32 |
| 音频 | ES8311 编解码 + NS4150B 功放，**喇叭内置** GSPK151035PN（8 Ω / 0.5 W，15×10×3.5）；J2 = MX1.25 2P 接线座，前腔右下 + 前壁出音孔 |
| 交互 | 右侧壁 **6 脚贴片三向拨轮开关**（L-ink S1 同款，上/下拨音量，按压对话；Φ10 轮露 2mm） |
| 供电 | USB-C 单口（左壁下方），5V→3.3V Buck ≥1A；**原生 USB-Serial/JTAG，可烧录/看日志** |
| 电池 | **不内置**，预留 VBAT/GND 焊盘，PMOS 自动切换 |
| 环境传感 | **AHT20 温湿度**（奥松）：复用 codec 的 I2C（GPIO41/42，固定地址 0x38，**零新增引脚**），板边热隔离槽 + 左壁通风孔，用于室温/湿度上报；**确定不加触摸** |
| 天线 | 模组自带 PCB 天线；屏顶距天线 12.4mm（低于建议 15mm，已做禁铜补偿） |

## 六条不能忘的约束

1. **AEC 参考信号必须从功放输出端取**，分压到 1Vpp 以内再进 ADC。ES8311 只有 1 路 ADC，硬件回采要另配 ES7210；否则只能软件参考，打断体验差一档。
2. **喇叭是 BTL 输出，两根线都不能接 GND**，也不能和电池负极共地。内置 8 Ω / 0.5 W 喇叭的 1.25T 端子插 J2，引线 35 mm。
3. **底面是桌面接触面**：零开孔、无外露螺丝，只留 4 个脚垫沉孔。
4. **AHT20 测的是室温**：器件必须远离模组/Buck/功放，通风孔全开在左壁（底面仍零开孔）；读数偏高先改布局与通风，不用软件偏移硬补。
5. **不做触摸**：AHT20 的 I2C 地址固定 0x38 且无 ADDR 脚，与常见电容触摸 IC 默认地址相同。以后要加触摸，必须换传感器（如可切 0x45 的 SHT30）或加 I2C mux，不能只改软件。
6. **内置喇叭必须限幅**：8 Ω 下 NS4150B 约 1.5 W，是 0.5 W 额定的 3 倍；ES8311 数字音量上限 −8 dB + 软限幅，提示音与拨轮调节都不得越过。同时前壁出音孔与泡棉密封缺一不可，否则密闭壳里听不见。

| rev 2.0 | 喇叭由外接改 **内置 GSPK151035PN**（8 Ω / 0.5 W）：占前腔右下 X 44–59 / Y 50–60，前壁新增 8–10 × Φ1.2 出音孔、泡棉圈围 ≈1.15 cm³ 后腔；BOM 新增 LS1；ES8311 音量上限 −8 dB。**机身尺寸、Z 叠层、壁厚、屏槽与全部既有开孔位置不变**；代价是放弃 19.5 mm 减薄备选 | 64×64×22 |
