# 小智 AI 板

基于 ESP32-S3 的桌面语音终端，可跑通 `xiaozhi-esp32` 官方固件：离线唤醒、全双工对话、波轮操作、1.3″ 屏表情。

当前状态：**结构方案 rev 1.7（64×64×22 + TF 卡）、显示屏接口设计定稿，尚未画原理图、未投板。**

## 核心规格

| 项 | 取值 |
|---|---|
| 整机尺寸 | **64 × 64 × 22 mm**（平放桌面，底面零开孔） |
| PCB | **58 × 52 × 1.6 mm**，4 层；顶部 6mm 天线禁铜 |
| 主控 | ESP32-S3-WROOM-1-**N16R8**（16MB Flash / 8MB PSRAM，R8 是硬门槛） |
| 显示 | **中景园 ZJY133T-IG01**：1.3″ IPS 240×240，ST7789V2，4 线 SPI，12pin 焊接 FPC（0.7mm 间距），自带背光 40mA；屏中心 (21.4, 33.0) |
| 存储 | **microSD（TF）**：SPI3 独立总线 20MHz，自弹式卡座在右壁上方，≤32GB FAT32 |
| 音频 | ES8311 编解码 + NS4150B 功放，**喇叭外接**（MX1.25 2P） |
| 交互 | 右侧壁 EC11 波轮（Φ24×4.0，旋转调音量 / 按压对话） |
| 供电 | USB-C 单口（左壁下方），5V→3.3V Buck ≥1A |
| 电池 | **不内置**，预留 VBAT/GND 焊盘，PMOS 自动切换 |
| 天线 | 模组自带 PCB 天线；屏顶距天线 12.4mm（低于建议 15mm，已做禁铜补偿） |

## 三条不能忘的约束

1. **AEC 参考信号必须从功放输出端取**，分压到 1Vpp 以内再进 ADC。ES8311 只有 1 路 ADC，硬件回采要另配 ES7210；否则只能软件参考，打断体验差一档。
2. **喇叭是 BTL 输出，两根线都不能接 GND**，也不能和电池负极共地。
3. **底面是桌面接触面**：零开孔、无外露螺丝，只留 4 个脚垫沉孔。
