## 1. 现在要做什么

**外壳已定稿，直接下单打样** —— 只需要 `外壳设计/cad/deliverables/` 里这三样：

| 文件                                       | 用途                                                           |
| ------------------------------------------ | -------------------------------------------------------------- |
| `ESP32S3_LCD_全覆盖外壳_上盖_3D打印.stl` | 上盖（含 9 组接口凸字，**必须用这一版**）                |
| `ESP32S3_LCD_全覆盖外壳_底座_3D打印.stl` | 底座（4 颗 M3 沉头自攻）                                       |
| `给商家的下单说明.txt`                   | 原样复制给商家：开口带分两组、窗口偏心是刻意的、后处理不要打磨 |

外形 `111.20 × 73.00 × 25.10 mm`（凸字顶 `25.50`），整套约 `38.45 cm³`。
建议 **SLA 光敏树脂**（凸字笔画约 `0.37 mm`，FDM 0.4 喷嘴可能断笔），价格约 `¥65~110`。

**硬件 V1.0 装配前必须改一处**：`R36`（`RT_PEN` / 触摸 INT）现在是 10K **下拉到 GND**，
GT1151Q 要求 **上拉到 3V3**，不改会出现触摸完全无响应（详见 [`硬件设计/V1.0-评审意见.md`](硬件设计/V1.0-评审意见.md)）。

## 2. 硬件接口速查（做扩展前必看）

### 2.1 已被占用的 GPIO

| GPIO                   | 用途                                            | 能否挪用                                                   |
| ---------------------- | ----------------------------------------------- | ---------------------------------------------------------- |
| `IO1~IO16`           | LCD 16 位数据 `DB0~DB15`                      | 不能                                                       |
| `IO17 / IO18 / IO21` | `LCD_WR` / `LCD_CS` / `LCD_RS`            | 不能                                                       |
| `IO38 / IO39 / IO40` | `LCD_RST` / `LCD_RD` / `LCD_BL`（背光）   | 不能                                                       |
| `IO41 / IO42`        | I²C `SCL` / `SDA`（触摸 + 4 个 4P 扩展座） | 不能，但可挂从机                                           |
| `IO46`               | 触摸 `INT`（**输入专用脚**）            | 不能                                                       |
| `IO47`               | 触摸 `RST`（V1.0 板已接死）                   | 不能（见下方提醒）                                         |
| `IO0`                | BOOT 按键（strapping）                          | 不能                                                       |
| `IO19 / IO20`        | USB D− / D+                                    | 不能                                                       |
| `IO45`               | `VDD_SPI` 电压选择                            | **绝对不能用**，拉高会导致 Flash 变 1.8V、直接不启动 |
| `IO35~IO37`          | N16R8 的 Octal PSRAM 占用                       | 不能（换 N8R2 才释放）                                     |
| `IO48`               | 核心板板载 WS2812（经 0 Ω）                    | 理论可断开 0 Ω 释放，实际不建议                           |

### 2.2 唯一现实可用的两个脚：`IO43` / `IO44`

这两个脚引到右侧 **J5（XH2.54-5P，顶板丝印 `UART`）**，原本是给 GNSS 模块的 UART1：

| J5 脚 | 网络        | 接到                                   | 说明                                                  |
| ----: | ----------- | -------------------------------------- | ----------------------------------------------------- |
|     1 | `GPS_VCC` | 3V3 或 5V（`JP1` / `H2` 跳线选择） | 串 `10 Ω` + 并 `100 µF`，只适合 <100 mA 的负载  |
|     2 | `GND`     | 底板地                                 |                                                       |
|     3 | `GPS_TX`  | **IO44**（ESP32 的 RX）          | 接模块的 TXD                                          |
|     4 | `GPS_RX`  | **IO43**（ESP32 的 TX）          | 接模块的 RXD                                          |
|     5 | `GPS_PPS` | `IO47`                               | 与触摸复位冲突，`H3` 默认不装，**PPS 不可用** |

> ⚠️ **旧手册的坑**：`硬件设计/ESP32S3-ATK-MD0350电容版-底板设计手册.html` 写「IO47 空闲，可做蜂鸣器 / 按键 / SD 卡 CS」，
> 那是 Rev C 的说法。**V1.0 板已把屏的 33 脚（触摸复位）接到 IO47**，所以 IO47 在这块板上不能再用。
> 以 [`硬件设计/引脚分配表-电容版.csv`](硬件设计/引脚分配表-电容版.csv) 和 `firmware/include/board_pins.h` 为准。

### 2.3 蜂鸣器 / 音频怎么接

**结论：能，但只能走 J5 这一路，且不是「把 UART 当音频线」。**

- **蜂鸣器（推荐，最简单）**
  - 有源蜂鸣器模块（3 脚 `VCC / GND / IN`）插 J5：`1→VCC`、`2→GND`、`3→IN`（IO44）。
  - **用 IO44 而不是 IO43**：IO43 是 `U0TXD`，上电 / 复位时 ROM 会吐 boot log 脉冲，蜂鸣器会「嘀」一声；IO44 是 `U0RXD`，静默。
  - 控制：有源蜂鸣器 GPIO 推高即响；无源蜂鸣器用 `LEDC` 输出 2~4 kHz 方波。
  - 供电：有源蜂鸣器约 15~30 mA，`10 Ω` 串阻压降 0.3 V 可接受。跳线选 3V3 更稳；选 5V 时注意「高电平触发」模块的阈值可能到 3.5 V，3.3 V 推不动，优先选低电平触发或带三极管的模块。
- **串口语音 / 放音模块**
  - `DFPlayer Mini`、`DY-SV17F`、`JQ8900`、`WT588F02B` 等：ESP32 通过 IO43/IO44 发指令，模块自己解码 MP3/WAV 并推喇叭，J5 的 5 脚刚好够（第 5 脚空着）。
  - ⚠️ **供电不能走 J5**：这类模块带功放峰值 0.5~1.5 A，`10 Ω` 串阻会直接压死。必须从 USB-C 的 5V（`F1` 之后）另拉，或模块独立供电、只共地。
- **高保真 I²S（不建议在这版做）**
  - ESP32-S3 **没有内置 DAC**，模拟音频只能靠外部 I²S 编解码；而 J5 只剩 2 个可用 IO，凑不出 `BCLK / LRCK / DIN` 三根。
  - 真要做得改板：牺牲 `IO48`（拆核心板上的 0 Ω RGB 灯）凑第三根，外挂 `MAX98357A`，并改固件。收益不大，不推荐。
- **既要 GPS 又要蜂鸣器**
  - 用 4 个 I²C 座之一（`CN1/CN2/CN4/CN5`，顶板丝印 `I2C1~I2C4`）挂 `PCF8574` / `AW9523` 扩展板，蜂鸣器、按键、继电器都能挂，地址可选不冲突（现有 `0x14` 触摸、`0x38` AHT20、`0x76` BMP280）。
  - 或直接选 I²C 接口的语音模块。**这是保留 GNSS 的唯一干净解法。**

### 2.4 外接 TMP117 温度探头

板载 AHT20 在壳内会被背光和 Wi-Fi 烤高 3~8℃。要测真实环境温度，用 **TMP117 外接探头**（±0.1℃、16bit、I²C `0x48`）：

- 插 **J4A / J4B 任意空座**（3V3 / GND / SCL / SDA），与触摸、AHT20、BMP280 同总线；两个座都满就用 XH 一分二线并接，或直接焊到 J4 四脚；
- 地址 `0x48`，与 `0x14 / 0x38 / 0x76` 不冲突；线长 20~50cm，`APP_I2C_FREQ` 保持 100kHz；
- 固件已支持：`sensors.cpp` 读 `0x0F` 校验 ID（`0x0117`）、读 `0x00` 出温度；TEMP 卡优先 TMP117，AHT20 只作湿度；
- 探头放到壳外，远离屏背光、ESP32、DC-DC。详见底板设计手册 **12.8**。

## 3. 常用命令

**重出外壳全套图纸**（改完 `外壳设计/cad/params_v2.py` 后必须六个脚本全跑）：

```bash
cd 外壳设计/cad
python build_v2.py          # STL / DXF / 报价 / 下单说明 / geom_v2.json
python make_pdf_v2.py       # 3 页 A4 工程图
python make_views.py        # A3 三视图 PDF + DXF
python build_step.py        # 3 个 STEP
python make_preview.py      # 俯视 / 等距预览 PNG
"C:/Program Files/FreeCAD 1.1/bin/freecadcmd.exe" build_fcstd.py
```

**编译固件**：

```bash
cd firmware
pio run                     # 编译
pio run -t upload           # 烧录
pio device monitor          # 串口监视（日志走 USB-CDC）
```

## 5. 注意

- 外壳材料**必须非金属、非导电**：禁止金属打印、碳纤填充、导电料、金属漆、电镀，否则屏蔽 2.4 GHz 天线。天线端由侧壁让位窗伸出，顶板完整不镂空。
- 外壳侧壁开口带**分两组，不是四边平齐**：下边双 Type-C `Z 6.00~16.20`，其余三边 `Z 4.00~12.20`。这是按「核心板在 PCB 之上」逐级累加算的，不是画错。
- 显示窗中心 `X=52.85 / Y=35.60` 相对外壳中心**左移 2.75、下移 0.90**，是刻意对位偏心屏。
- 若本仓库转为公开：`外壳设计/ref/esp32s3_lcd/ESP32S3_LCD.epru` 是完整 EDA 工程源，`外壳设计/ref/输入资料/` 含 PCB 导出图，推送前请确认。
