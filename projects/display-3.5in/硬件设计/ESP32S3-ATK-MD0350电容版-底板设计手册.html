电容版和电阻版差得比想象中大，三条必须先记住
  1. 触摸是 I²C，不是 SPI。34P 排针上：30 脚 = IIC_SDA、34 脚 = IIC_SCL、31 脚 = 触摸中断、33 脚 = 触摸复位，29 脚（MISO）与 32 脚（BUSY）悬空。网上大量「3.5 寸屏接 XPT2046」的教程在你这块屏上完全不适用。
  2. 33 脚丝印叫 CS，但它是触摸复位，不是片选。排针命名沿用老版本，照着丝印接成 CS 的话，触摸永远初始化失败。
  3. 显示侧仍是 16 位 8080 并口，没有 SPI 模式。DB0~DB15 一根不能少，ESP32-S3 只能用 LCD_CAM 的 i80（Bus_Parallel16）。
V2.4（旧资料）与 V3.0（新资料）的 34P 定义一致 两版原理图的排针顺序和触摸复用方式完全相同（29/32 为 NC、30=SDA、31=INT、33=RST、34=SCL），所以这份底板对两版都成立，不会因为资料版本不同白画。

2.1 带宽够不够

16 位总线一个 WR 周期送一个像素。freq_write = 20MHz 就是 2000 万像素/秒，480×320 = 15.4 万像素，理论 130fps，实际 DMA + LVGL 能跑到 45~60fps，够用。40MHz 是 ESP32-S3 i80 在 16 位模式的上限，PCB 上可以试。

6.2 必须加的 6 个上下拉

网络阻值方向不加的后果
LCD_CS10K上拉 3V3上电 CS 悬空，屏可能响应总线噪声
LCD_RD10K上拉 3V3RD 被噪声拉低时屏驱动总线，与 MCU 对撞
LCD_BL10K下拉 GND上电背光闪一下白屏
LCD_D2（IO3）10K下拉 GNDIO3 是 JTAG 源 strapping，浮空可能误选外部 JTAG 脚
TP_INT10K下拉 GNDI²C 地址不确定，触摸可能扫不到；中断脚浮空易误触发
TP_RST10K上拉 3V3固件未接管前触摸一直处于复位态

I²C 的 SDA/SCL 不必在底板加上拉：模块内 R11/R12 已有 4.7K。只有排线很长或通信不稳时，才把 BOM 里可选的 R11/R12 焊上（并联后约 2.35K）。

6.3 触摸上电时序（固件要照着做）

GT9 系列上电顺序错一步就扫不到地址，硬件画对之后这一步最容易翻车：

1. +3V3 上电，等 ≥ 10 ms
2. TP_INT 保持低（底板 10K 下拉已保证）
3. TP_RST 拉低，保持 ≥ 10 ms
4. TP_RST 释放为高；GT1151Q 地址固定 0x14（GT911 才会用 INT 电平选址）
5. 再等 ≥ 50 ms（触摸 IC 加载配置）
6. 依次探测 0x14 / 0x5D，读到产品 ID（GT1151Q 返回 "1158"）即成功
7. 之后 TP_INT 当普通中断输入：低/下降沿 = 有触摸
别把 TP_RST 接到 ESP32 的 EN 上省引脚 触摸复位必须和 MCU 复位解耦：ESP32 下载或重启时不能顺带把触摸复位掉，否则地址选择时序会乱。这一根线值得单独占用 IO48。

6.4 复位与启动

  • EN：10K 上拉 + 1µF 到 GND + 按键到 GND。
  • IO0：10K 上拉 + 按键到 GND，不要加下拉。
  • IO45：悬空或 10K 下拉，绝不能上拉。

07PCB 布局布线要点

布局顺序

  1. J2 排母先定：位置由屏的排针决定，1 脚丝印要显眼。
  2. USB-C 放板边，离屏最远的短边。
  3. ESP32-S3 夹在中间，天线朝板外，天线区 15mm 内禁铜。
  4. DC-DC 靠 USB-C，远离数据总线。

布线顺序

  1. 16 根数据线成束、同层、扇出。
  2. WR 最短，两侧留 3W 间距。
  3. CS/RS/RST 随数据线走。
  4. I²C 两条线并行走、尽量短，远离 WR 与数据总线。
  5. 底层整片地。

9.1 点不亮 / 触摸不响应的排查顺序

  1. 背光：把 BL 短接到 3.3V，应看到白屏或花屏。看不到 → 供电或排母接触问题。
  2. 降频：freq_write = 10MHz。
  3. 花屏 / 错位：优先怀疑 D0~D15 顺序错位，用「逐位取反」的单色测试定位。
  4. 触摸扫不到：先量 TP_RST 是否真接在 33 脚、复位后是否为高；再探测 0x14 / 0x5D 的产品 ID。
  5. 坐标翻转 / 偏移：调 offset_rotation 与 x/y 的 min/max。

9.2 显示器驱动 IC 的坑（重要）

旧版手册写的是 NT35310，不是 ST7796 《ATK-MD0350 模块用户手册》（旧资料）明确写「LCD 驱动器芯片：NT35310」，新资料写「NT35310 或 ST7796」。两者引脚一致，底板不用改，但初始化序列不同：
  • LovyanGFX 没有 Panel_NT35310。先用 Panel_ST7796 试；不行再试 Panel_ILI9488。
  • 都不行时，正解是按 NT35310 初始化表在 LovyanGFX 里写自定义 Panel 类（继承 Panel_LCD，覆写 init 命令表），工作量不大。
  • 底板上把 LCD_RD 接到 IO39 并留了上拉，就是为了必要时能读回 ID（0x04 / 0xD3）确认型号——固件把 readable 打开、pin_rd 设为 39 即可。

11备选：插现成核心板的简化版

如果你有 ESP32-S3-DevKitC-1，想先验证屏，可以只做「排母 + 排母」的转接底板，不做电源。

优点

  • 不用焊模块、不用调电源
  • 核心板自带 USB / LDO / 按键
  • 坏了换核心板

代价

  • 总高 +10mm，三层三明治
  • 核心板 LDO 多为 500mA 级，背光全亮 + Wi-Fi 峰值可能掉压
  • GPIO 号以核心板丝印为准

做法：把第 4 节的 GPIO 号直接对到核心板丝印接线；6 个上下拉照样要加，尤其是 TP_INT 的 10K 上拉——实测这颗 GT1151Q 靠它在复位时选地址（上拉→0x14）。

12扩展外设：AHT20 + GY-BMP280 + ATGM336H-5N31

12.5 温湿度传感器最容易被做坏的地方

AHT20 放板中央，温度会偏高 3~8℃ 这块板的 3.3V 轨上跑着 82mA 背光和峰值 355mA 的 Wi-Fi，板子中间就是个热源。AHT20 必须：
  • 放在板边、远离背光排线和 DC-DC，最好靠近外壳的通风口；
  • 传感器周围开透气孔（Φ1.5mm，3~5 个）或直接伸出板边；
  • 如果装在屏后面的密闭腔体里，读数基本没有参考价值——这种情况必须把传感器单独引出去。

12.7 固件要点

  • 驱动都写在工程里（src/sensors.cpp），不引第三方库——这台机器上 PlatformIO 装新依赖会再次卡在下载和删除钩子上，保持零新增依赖最稳。
  • I²C 走 lgfx::i2c，和 GT911 同一个端口（I²C_NUM_0），避免 Arduino Wire 二次初始化打架。
  • GPS 用 Serial1（UART1）绑到 IO44/IO43，9600 8N1；只解析 $GNRMC 与 $GNGGA 就够用。
  • 气压用 BMP280 的 float 补偿算法（Bosch 数据手册 3.11 节）；温度建议优先用 AHT20 的读数，BMP280 自身温度精度只有 ±1℃。
  • 室内基本定不到位，测试时把 GPS 拿到窗边或室外，冷启动等 30~40 秒。

12.5 改成可插拔：接插件选型与引脚定义

三个外设全部改用带锁扣的 XH2.54 座，线用成品 XH 端子线。插错方向物理上插不进去， 拔插也不用拧螺丝——这比 2.54 排针 + 杜邦线安全一个量级。

方案锁扣防反插评价
XH2.54（推荐）有有3A 载流、成品线 2 元一根、手插不费劲；2.5mm 间距，底板上占位适中
PH2.0摩擦有更省地方，很多 GPS 模块原配就是它；线细，自己压端子麻烦
Grove / SH1.0有有最紧凑，但 5P 没有 Grove 标准，三路会变得不统一
2.54 排针 + 杜邦无无不要用：反插一次 VCC 直接怼到 GND 或 SDA 上，传感器当场报废

13插座版供电：一根 Type-C 同时喂核心板和屏

底板用 2×22 排母插 YD-ESP32-S3 核心板时，不能照第 5 节那样把 3.3V 直接送给模组—— 核心板自带 LDO 和两个 USB 口，电源要从它的 5V 脚进。下面这套是核对过核心板原理图后的接法。

13.3 5V 到核心板：为什么建议直连

方案压降结论
直连（推荐）0 V核心板两个 USB 的 VBUS 各串了一颗 D26 肖特基到 5V 网络，电流倒灌不进 PC；两个 5V 源并联没有风险
串 SS34 肖特基0.4 V不推荐：核心板 5V 只剩 4.6V，它上面的 AMS1117 类 LDO 在 Wi-Fi 峰值（355mA）时容易掉压复位
P-MOS 理想二极管≈0.05 V要严格防止底板被核心板 USB 反供电时用，多两只元件（AO3401 + 100K）
最容易犯的错：把底板的 +3V3 也接到核心板的 3V3 脚。
核心板的 3V3 是它自己 LDO 的输出，两边对顶会互相灌电流——轻则 LDO 发热、重则 Wi-Fi 一突发就复位。 要么只给 5V（推荐），要么拆掉核心板上的 LDO 才谈得上共轨。

13.6 上电自检四步

  1. 只插底板 Type-C（不插核心板 USB）：量 TP1 应在 4.9~5.2V。
  2. 量 +3V3：3.25~3.35V。偏离多半是反馈电阻焊错或电感虚焊。
  3. 插上核心板，跑 Wi-Fi 再看一次 5V 与 3V3——掉到 3.0V 以下就要查 L1 饱和电流和 C_out。
  4. 屏背光亮、触摸能扫到 0x14：电源这部分就算过了。

13.7 五个画错的概率最高

  • CC 用 56K 上拉（那是 source 的接法），结果 C-to-C 线插上没反应。
  • VBUS 只连 A4/A9，漏了 B4/B9——反过来插就不通电。
  • 把 +3V3 接到核心板 3V3 脚，和板上 LDO 对顶。
  • 屏座旁只放 100nF 不放 100µF，开背光瞬间 3V3 被拉塌，表现是白屏或闪一下黑。
  • 电感和 SW 节点贴着排母 / FPC 排线走，干扰串到 I²C 上，表现是触摸偶发丢点。
